# Word & Line Counter CLI

A simple Node.js Command Line Interface (CLI) tool that reads a text file and calculates total lines, words, and characters.

## Features
- Reads text files asynchronously using Node's `fs/promises`.
- Counts total lines, words, and characters.
- Gracefully handles missing files using `try/catch`.
